# 習慣管理の要件定義

第3弾。スケジュールで作った繰り返しの展開（`src/lib/recurrence/`）と、
家族・メンバー・認可（RLS）をそのまま使う。

## 1. 目的

**続いているかどうかが見える状態**にする。

記録をためること自体が目的の機能である（00-product-vision.md 4.4）。
予定と違い、やらなかったことが「できなかった」という情報になる。

そのため設計は次の順で判断する。

1. 今日やることが、開いた瞬間に分かるか
2. 押すのが速いか
3. 続いているかどうかが見えるか
4. 分析ができるか

## 2. 使い方の前提

| | 内容 |
| --- | --- |
| 対象 | 家族全員。子どもの手伝い・歯みがき、大人の運動・読書 |
| 習慣の数 | **1人あたり1〜5個**。10個を超えたら続かないサイン |
| 押す頻度 | 1日1回〜数回。朝と夜が多い |
| 押す場所 | スマートフォン |
| 見る頻度 | 毎日（今日の一覧）＋ 週に1回（続いているか） |

**開いてから押し終わるまで5秒**を目標にする。家計簿より短い。
金額のような入力が無く、押すだけだからである。

## 3. 先に決めたこと

### 3.1 習慣は予定ではない

00-product-vision.md 4.4 の表のとおり、別のデータとして持つ。
繰り返し予定として実装すると、カレンダーが未達成の習慣で埋まる。

### 3.2 頻度は2種類ある。**RRULE だけでは足りない**

| 言い方 | 表し方 |
| --- | --- |
| 毎日 / 平日 / 月・水・金 | **RRULE**（`FREQ=WEEKLY;BYDAY=MO,WE,FR`） |
| 週3回 / 月10回（曜日は問わない） | **回数**（期間と回数を持つ） |

RRULE は「週3回、曜日は問わない」を表せない。
どちらか片方に寄せると、次のどちらかが壊れる。

- 回数だけにすると「毎週火曜のゴミ出し」が表せない
- RRULE だけにすると「週3回走る」が「月水金に走る」になり、
  火曜に走った日が未達成のまま残る

**そのため2種類を持つ。**種類は習慣ごとに選ぶ。

### 3.3 記録は「やった日」だけを持つ

**「できなかった」は記録しない。**記録が無い日が、やらなかった日である。

明示的に「できなかった」を残せるようにすると、
押し忘れと、やらなかったことが区別できなくなる。
どちらも「記録が無い」で足りる。

### 3.4 1日に1回まで

同じ習慣を1日に2回押しても2回にはならない。
回数を数えたい習慣（腕立て30回）は、この機能では扱わない。
**やったかどうかだけを持つ。**量を持つと、目標の設定と単位の管理が付いてくる。

### 3.5 公開範囲は習慣ごとに選ぶ

記録が家族に見えるのは後押しになるが、見張られている感じにもなる
（00-product-vision.md 4.4）。

| 範囲 | 見える人 |
| --- | --- |
| **家族**（既定） | 家族の全員 |
| 自分だけ | 作った本人のみ。記録も見えない |

家計簿と違い、ここは秘密を認める。家計は共有の財布だが、習慣は個人のものである。

### 3.6 過去の日も押せる。ただし未来は押せない

寝る前に「今日の分」を押し忘れることがある。
さかのぼって押せないと、記録が実態と合わなくなる。

未来は押せない。まだ起きていないことを記録できると、記録の意味が無くなる。

## 4. 機能要件

### 4.1 習慣

| ID | 要件 | 優先度 |
| --- | --- | --- |
| FR-H01 | 習慣を登録できる。項目は 名前・担当する人・頻度・公開範囲・色 | Must |
| FR-H02 | 担当する人は**1人**。家族で1つの習慣は作らない（4.1 の補足） | Must |
| FR-H03 | 頻度は「曜日で決める」か「回数で決める」のどちらか（3.2） | Must |
| FR-H04 | やめた習慣は隠せる。記録は残る | Must |
| FR-H05 | 習慣を編集できる。頻度を変えても過去の記録は動かない | Must |
| FR-H06 | 量（回数・時間）は**持たない**（3.4） | — |

FR-H02 の補足: 「家族全員で早寝」のような習慣は、1人ずつ登録する。
共有にすると「誰が押したのか」「全員押したら達成か」を決めることになり、
押すのが速いという取り柄が消える。

### 4.2 今日の一覧

| ID | 要件 | 優先度 |
| --- | --- | --- |
| FR-H10 | 今日やることが、開いた瞬間に出る | Must |
| FR-H11 | 押すと記録になる。もう一度押すと取り消せる | Must |
| FR-H12 | 自分のぶんが先に出る。家族のぶんはその下 | Must |
| FR-H13 | 今日やることが無い習慣は出さない（週3回のものは、達成済みなら出さない） | Must |
| FR-H14 | 過去の日にさかのぼって押せる。未来は押せない（3.6） | Must |

### 4.3 続いているか

| ID | 要件 | 優先度 |
| --- | --- | --- |
| FR-H20 | 連続している日数が見られる | Must |
| FR-H21 | 直近4週間の達成率が見られる | Must |
| FR-H22 | 直近の記録が、日ごとの並びで見られる | Should |
| FR-H23 | 家族のぶんも見られる（公開範囲が「家族」のもの） | Should |

**連続日数だけを主役にしない。** 途切れた瞬間に「もういいや」になる。
達成率と並べて出し、1日抜けても続きが見えるようにする。

### 4.4 カレンダーに出す

| ID | 要件 | 優先度 |
| --- | --- | --- |
| FR-H30 | 習慣ごとに、カレンダーに出すかを選べる。既定は**出さない** | Could |

**後回しにする。** スケジュールの画面に手を入れることになり、
毎日見る画面を習慣の都合で触りたくない。使ってみて欲しくなったら足す。

## 5. データモデル

```
families ──┬── habits       習慣
           └── habit_logs   やった日
```

| テーブル | 主な列 |
| --- | --- |
| `habits` | `family_id` `member_id` `name` `color` `kind(schedule/count)` `rrule` `target_count` `period(week/month)` `visibility(family/private)` `is_active` `created_by` |
| `habit_logs` | `habit_id` `done_on(date)` `created_by` — 主キーは `(habit_id, done_on)` |

`habit_logs` の主キーが `(habit_id, done_on)` であることが 3.4 の担保になる。
**1日2回は、行として存在できない。**

`rrule` はスケジュールと同じ文字列。`kind = 'schedule'` のときだけ使う。
`target_count` と `period` は `kind = 'count'` のときだけ使う。

## 6. 画面

| 画面 | 場所 | 内容 |
| --- | --- | --- |
| **今日** | `/habits` | 今日やることの一覧。押して記録 |
| 記録 | `/habits/log` | 連続日数・達成率・日ごとの並び |
| 習慣 | `/settings/habits` | 登録と編集 |

**「今日」を機能の入口にする。** 毎日開くのはこちらで、登録は最初の1回だけ。

## 7. 受け入れ基準

| ID | 基準 |
| --- | --- |
| AC-H01 | 画面を開いてから、今日のぶんを押し終わるまで5秒以内 |
| AC-H02 | 今日やらない習慣が一覧に出てこない |
| AC-H03 | 「自分だけ」の習慣が、他の家族から見えない（記録も） |
| AC-H04 | 未来の日は押せない |
| AC-H05 | 連続日数と達成率が、1画面で分かる |
| AC-H06 | 画面幅375pxで押すのが完結する |

## 8. 作る順番

| | 内容 | 規模 | 状態 |
| --- | --- | --- | --- |
| H1 | 習慣の登録・今日の一覧・押して記録 | 中 | **済** |
| H2 | 続いているかの振り返り（連続日数・達成率） | 小 | |
| H3 | カレンダーに出す（4.4） | 小・後回し | |

H1 が終わった時点で**毎日使える**状態になる。

H1 でやったこと:

- 習慣の登録（`/settings/habits`）。名前・する人・頻度・公開範囲・色
- 今日やること（`/habits`）。行のどこを押しても記録になる
- もう一度押すと取り消せる。押し忘れた日にさかのぼれる。未来は押せない
- 「自分だけ」の習慣は、家族から習慣も記録も見えない

**連続日数と達成率の数え方は H1 で作ってある**（`src/lib/habit/model.ts`）。
画面（H2）で使うだけの状態。要点は2つ。

- **連続は「やる日」だけを数える。**毎週月曜の習慣を月曜にやり続けているなら
  途切れていない。日を空けずに数えると、週1の習慣はいつも「1」になる
- 回数で決めるものは、**届いた期間の数**で数える。日で数えると週3回の習慣が
  いつも1〜2で止まる

## 9. 決めること

| 項目 | 案 | 確認 |
| --- | --- | --- |
| 担当は1人か | 1人。家族共有の習慣は作らない（FR-H02） | 要確認 |
| 量を持つか | 持たない。やったかどうかだけ（3.4） | 要確認 |
| 週の区切り | スケジュールの「週の開始曜日」に合わせる | 要確認 |
